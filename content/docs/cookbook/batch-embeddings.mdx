---
title: Batch embeddings
description: Embed many inputs in one call.
---

```python
from volt import Volt

client = Volt()
resp = client.embeddings.create(
    model="bge-large-en-v1.5",
    input=["zero egress", "metro pinning", "measured boot"],
)
for e in resp.data:
    print(f"input {e.index}: dim={len(e.embedding)}")
```

`input` accepts a single string or a list. Embeddings run on MIG-partitioned L40S
and are eligible for both the standard and sovereign tiers.
